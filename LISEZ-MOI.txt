DIAGONIO — version 4, refonte visuelle (édition esthétique)

Cette édition conserve les fonctions et le format de données de DIAGONIO v4 ; elle améliore principalement l'interface : identité bleu marine/orange, fond clair, champs et boutons plus confortables sur téléphone, cartes mieux hiérarchisées et nouvelle icône. Le fonctionnement hors ligne reste assuré par le service worker.

Les clés de stockage local des appareils et de l'historique n'ont pas été modifiées. Si vous mettez à jour une installation existante sur la même adresse web et dans le même navigateur, les données locales doivent donc rester présentes. Par prudence, exportez tout de même une sauvegarde JSON complète avant de remplacer les fichiers.

APPLICATION DE DIAGNOSTIC — RHOTHETA RT-300 / TAIYO TD-L1550A
Version initiale, française, destinée à l'équipage.

CONTENU
- index.html : application autonome, formulaires, arbre de diagnostic, historique local, impression PDF.
- manifest.json : métadonnées d'installation PWA.
- sw.js : cache hors connexion.
- icon.svg, icon-192.png, icon-512.png : icônes.

TEST RAPIDE
Ouvrir index.html dans un navigateur pour tester les fonctions de diagnostic et d'impression.
L'historique est enregistré dans le stockage local du navigateur.

INSTALLATION SUR IPHONE / IPAD ET ANDROID
Pour une véritable installation PWA avec fonctionnement hors connexion, héberger ces fichiers sur un site HTTPS (serveur web de l'organisation, intranet compatible HTTPS ou hébergement statique HTTPS).
- Android : ouvrir l'URL dans Chrome/Edge puis choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- iPhone/iPad : ouvrir l'URL dans Safari, toucher Partager, puis « Sur l'écran d'accueil ».
Ouvrir directement le fichier HTML local permet de tester l'application, mais ne garantit pas l'installation PWA ni la mise en cache hors connexion.

DONNÉES / CONFIDENTIALITÉ
Les fiches restent dans le navigateur et sur l'appareil. Elles ne sont pas synchronisées. Exporter régulièrement l'historique JSON pour sauvegarde/transfert. L'effacement des données du navigateur peut supprimer l'historique.

PDF
Le bouton de rapport ouvre la boîte de dialogue d'impression du navigateur. Choisir « Enregistrer au format PDF ».

LIMITES IMPORTANTES
Les pistes sont heuristiques, non validées par le constructeur, et ne prouvent pas une panne. Les contrôles sont volontairement limités à l'équipage et aux observations non invasives. Ne pas ouvrir l'appareil, ne pas accéder à une antenne en hauteur, ne pas intervenir sur des câbles sous tension, et ne jamais émettre sur une fréquence de détresse pour tester. Suivre les procédures du navire et les notices constructeur. Ce logiciel ne remplace pas l'équipement opérationnel, les procédures SAR ou un technicien qualifié.

VALIDATION REQUISE AVANT USAGE OPÉRATIONNEL
Faire relire les libellés et l'arbre de diagnostic par le responsable électronique/maintenance du navire et comparer chaque procédure avec la version exacte des notices à bord.
